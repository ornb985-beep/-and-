# AI竞品分析流程

> [!abstract] 一句话
> 五步：采集 → 放进 raw → AI 写摘要和对比 → 每周体检 → 下周只改一处。人负责看和判断，AI 负责整理和对比。

## 要点

- 采集：官方后台（罗盘、视频号助手）、付费工具（蝉妈妈、飞瓜、友望）、3 分钟人工记录。
- 放进 raw：公开报告用 Web Clipper，直播观察用竞品雷达。
- AI：按[[拆解七步]]把话术映射到五道门和四要素；按[[价格带地图]]归类；按[[金色仿品红线]]查合规。
- 每周体检：哪些对手换了打法、哪些结论过时。
- 决策：每周只选一件事改（[[每场只改一个问题]]）。

## 怎么用

- 对 Claude Code 说：「按 AGENTS.md 录入 raw/ 里新的竞品观察，更新竞品分层和价格带地图，列出本周最值得学的一句话术」。
