# 讲品五步与讲品六步

> [!abstract] 一句话
> 面试 SOP 的「讲品五步」是镜头动作层面的写法，训练体系的「讲品六步」是内容层面的写法，指的是同一件事。

| 六步（内容） | 五步（镜头动作） |
| --- | --- |
| 痛点 | 抓人 |
| 卖点 · 场景 | 拆价值 |
| 福利 | 造反差 |
| 质保 | 立背书 |
| 逼单 | 逼单 |
