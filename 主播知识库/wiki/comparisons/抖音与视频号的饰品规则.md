# 抖音与视频号的饰品规则

> [!abstract] 一句话
> 两个平台都要求如实写材质；视频号对金色仿品一刀切禁售，抖音的说法随版本变过。

|  | 抖音 | 视频号（橱窗） |
| --- | --- | --- |
| 类目 | 时尚饰品（非天然宝玉石、非贵金属、较低价的银） | 珠宝首饰 › 时尚饰品，定向准入 |
| 金色仿品 | 2022 细则禁售；2023 解读：合金镀金有条件可售 | 禁售：铜合金、塑料镀金、银镀金、包金 |
| 材质描述 | 标题、详情、直播间都要如实说明 | 标题必须写材质：品牌 + 材质 + 款式 + 重量 |
| 质检 | 部分品类 QIC，一物一检 | 按类目规则 |

- 规则会改：上架前以后台当期规则为准。
