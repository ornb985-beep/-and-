# 平替与设计款

> [!abstract] 一句话
> 平替卖的是「像」，设计款卖的是「好看、适合我」。前者在视频号碰红线，后者是我们的路。

|  | 黄金平替 | 设计款 |
| --- | --- | --- |
| 顾客在买什么 | 像金子，便宜 | 风格、场景、情绪价值 |
| 平台规则 | 视频号禁售金色仿品 | 如实写材质即可 |
| 对手 | 义乌白牌，同款极多 | 新品牌更新快，靠讲品和复购 |
| 话术 | 「跟黄金一样」（违规） | 「白衬衫也压得住」「送人拿得出手」 |
