# ══════════════════════════════════════════════════════════════════
#  规则库 —— 改这个文件，系统行为就变，不用改代码
# ══════════════════════════════════════════════════════════════════
#
#  每个 [方括号] 是一条规则。改完存盘，页面点「重新生成」即生效。
#
#  可用的键：
#    成分      1=补格式 2=异常必问 3=战术纠正 4=心法（默认 3）。决定草稿里的先后
#    命中词    逗号分隔。主播复盘里出现任意一个词就算命中
#    至少几次  可选。要出现这么多次才算命中（默认 1）
#    条件      可选。数据条件（见下表）。可写多个＝全部满足才命中；
#              与「命中词」同时写＝两边都要满足
#    被抑制于  可选。填别的规则名。那条也命中时这条就不发
#              （比如主播发烧那天，就别催她补复盘格式了）
#    回复      命中后写进草稿的话。这是老板自己的原话，随便改
#    跟进      可选。命中后自动挂到明天，第二天必查
#    无对策    可选。填「是」＝语料里老板从没答过这类，草稿显式标出而不是编一条
#    达标时也发 可选。默认达标那天不发战术纠正——数据好时挑毛病最伤人。
#              少数规则（如「大涨」要记下为什么行）要照发，填「是」
#    来源      可选。这条规则从哪句话提炼，方便回溯
#
#  条件词表（只认这几个，写错会在启动时报出来）：
#    复盘缺项 · 时长不足 · 未达标 · 严重未达标 · 达标 · 连续未达标 · 大跌 · 大涨
#    （严重未达标 = 只做到目标的一半或更少）
# ══════════════════════════════════════════════════════════════════

回复 = 复盘按完整模板来，缺的那几项补一下，我好把数据记全

成分 = 2
条件 = 时长不足

# ── 成分 3 · 战术纠正 ──────────────────────────────────────────────

[反复重开]
命中词 = 重开, 重新开
至少几次 = 2
回复 = 少重开，重开也接不住人。先把场控住，稳在自己的节奏里
跟进 = 明天少重开，人少就耐心等，看看靠控场能不能把人留住
来源 = 主播多次自述「重开也没人」

[人少接不住]
命中词 = 人少, 流量小, 流量差, 没什么人, 人不多, 不精准
回复 = 人少正是练话术的最好时机。别急着重开，一对一去 cue，像跟朋友聊天那样慢慢来
跟进 = 明天人少的时段试一对一 cue，看停留有没有变长
来源 = 场控经验

[人多接不住]
命中词 = 人多, 好多人, 没接住, 顾不上, 流速大, 人很多
回复 = 人多千万别急，按住节奏，先控场，多讲信任话术，让大家跟着你走
来源 = 场控经验

[没人点讲解]
命中词 = 没人点, 很少人点, 不点款, 没有人点讲解
回复 = 没人点讲解也别等，自己主动过款，先过你最擅长讲的品。有人点了优先过，让人感觉被重视
来源 = 讲品经验

[话术格式化]
命中词 = 格式化, 亲和力, 距离感, 硬邦邦, 太直白, 僵硬, 像背稿
回复 = 讲人话，像面对面跟朋友聊，把信任话术揉进自己的话里，先破冰再讲品
跟进 = 明天重点练亲和力，看留人和停留有没有起色
来源 = 表达问题

[状态差]
命中词 = 累, 状态一般, 头疼, 发烧, 麻木, 迷茫, 怀疑人生, 提不起劲
回复 = 别播到麻木，脑子在线、跟用户有链接就行。可以直接说「咱们慢点，我给你们讲清楚」，把节奏调到自己舒服的位置
来源 = 状态调节

[拍了不付款]
命中词 = 拍了不付款, 只拍不付, 拍下不付, 不付款
无对策 = 是
来源 = 语料里老板从未回应过这一类——这是明确缺口，不许编


# ── 成分 4 · 心法（按当天结果二选一）────────────────────────────────

[达标收尾]
成分 = 4
条件 = 达标
回复 = 胜不骄败不馁，保持平常心，稳住。休息好、体力足，才能游刃有余地驾驭各种流量
来源 = 达标日心法

[未达标收尾]
成分 = 4
条件 = 未达标
回复 = 对应情况对应策略，遇到问题解决问题，多经历就从容了。清楚自己的短板和优势，每天这样就稳
来源 = 未达标日心法

[严重未达标]
成分 = 4
条件 = 严重未达标
回复 = 今天差得比较多，别一句「流量不好」带过。把开场那半小时回想一遍：进来的人留住了吗，第一个价开在什么时候
跟进 = 回想今天开场半小时的留人和开价时机，明天调一处试试
来源 = 严重未达标必盯

[连续未达标]
成分 = 4
条件 = 连续未达标
回复 = 连着几天没到目标了，把问题拆开看：是流量的问题还是承接的问题？明天挑一个点专门练
跟进 = 连续未达标，明天单独看一次：问题到底出在流量还是承接
来源 = 连续未达标拆因


# ── 数据异动 ────────────────────────────────────────────────────────

[大涨]
条件 = 大涨, 达标
达标时也发 = 是
回复 = 今天数据很好，把为什么行记下来——什么品跑起来了、什么节奏留住了人，这才是能复用的
跟进 = 复盘今天为什么涨：哪个品、什么节奏，写下来
来源 = 大涨要固化经验

[大跌]
条件 = 大跌
回复 = 今天比这几天低不少。先别急着归因到流量，把开场半小时的回放看一遍，重点看留人和开价时机
跟进 = 看今天开场半小时回放，重点看留人和开价时机
来源 = 大跌先看回放
