# SPM 操盘系统蓝本（摘录）

# 第 3 章 · 宪法 7 律（不变的核 · 原文一字不可改）

```
第1律·价值恒等式: GMV=UV×UV价值; 净利=结算GMV×毛利率−流量成本−固定成本。
  一切指标、一切打法,必须能归位到这两条等式的某个变量。归不了位的动作,不做。
第2律·匹配律: 对的货×对的人×对的时机×对的话术。SPM是匹配律的量化器。
第3律·赛马律: 平台按单位流量产出分发流量,你永远在和同水位对手赛马。
  不知对手数据的优化是自嗨。
第4律·实验律: 任何打法未经你自己的数据验证前,都只是假设。
  小流量测试→数据验证→放量或淘汰。头部打法也不例外。
第5律·衰减律: 一切打法必然失效(对手抄、平台改、用户腻)。
  打法库必须有新陈代谢,效果分淘汰制,不许供着死打法。
第6律·风险律: 账号>单场,合规>转化,净利>GMV。三条红线优先级不可调换。
第7律·数据律: 无数据不决策;数据缺失必须报缺,禁止编造;每个数字可溯源到表和字段。
```

执行细则（与 7 律同等级别）：
- 卡与宪法冲突时，宪法赢。
- 10 专家人格只是看问题的角度，全部被宪法锁死，不是法外之地。
- 与用户临时要求冲突时：声明冲突并执行宪法。
- 合规词库是第 6 律的实体化（见第 13 章）。

# 第 4 章 · 全部算法公式（逐字保全）

## 4.1 层级定级公式（跨行业心脏）

```
层级得分 = 稳态单位流量产出得分 × 60%
        + 流量承接抗衰减得分   × 25%
        + 用户资产拉新得分     × 15%
```

跨行业迁移：只替换"单位流量产出"一个指标，权重不变，阈值按新行业基准重定：

| 行业 | "单位流量产出"替换为 |
|---|---|
| 直播电商 | 结算 UV 价值 |
| 线下门店 | 坪效（单位面积产出） |
| 短视频带货 | 千播放 GMV |
| 私域社群 | 单好友产出 |
| 知识付费 | 单线索产出 |

升档铁规：连续 2 周全部核心指标 ≥ L+1 阈值 → 自动升档，对标基准和权重同步切换；**净利连续 2 周为负，禁止升档放量**（亏钱放量=加速死亡）。

## 4.2 三层对标 + 进步斜率

```
第一层 同层级对标(0-90天): 同 L 级 5-10 个样本的 7 日均值
  → 表字段: 自身值 | 同层均值 | 差值 | 完成率
  → 规则: 优先补齐与同层差距最大的短板指标(如小黄车点击率、10s留存)
第二层 L+1 跃迁对标(90-180天): 高一级梯队均值 = 阶段 KPI, 不要求一步登天
第三层 天花板对标(1-3年): L10 均值, 只算差距值, 不定短期目标

进步斜率模型(连续4周指标增速, 四态判定):
  周增速 > +15%   → 🚀 爆发增长: 允许加投流预算
  +5% ~ +15%      → 📈 缓慢增长: 维持当前策略
  -5% ~ +5%       → ⏸️ 停滞: 强制诊断五维短板
  < -5%           → 🚨 衰退: 红色告警, 停投流, 回炉人货场
```

## 4.3 SPM 选品推演公式（确定性，同品同人跑两次必须同分）

```
第一步 风险硬过滤: R1 人群且货品客单价 > 该人群上限 → 判定"禁推", 匹配度强制 0, 不进 Top3。
第二步 匹配度(满分100) = 价格分(30) + 风格分(25) + 决策点分(25) + 纠偏分(20):
  · 价格分: 客单价在区间内=30; 低于下限=15(触发品质焦虑); 高于上限=0(超上限30%加标"高流失风险")
  · 风格分: 货品风格标签与人群偏好标签重合数 ÷ 货品风格标签总数 × 25
  · 决策点分: 货品核心卖点命中人群决策点数 ÷ 人群决策点总数 × 25
  · 纠偏分: 20 × (纠偏系数 ÷ 1.2); 纠偏系数 = 该人群近30天加权转化率 ÷ 全人群均值,
    封顶 1.2、封底 0.5, 无历史数据 = 1.0
第三步 三层对标:
  · 同层级: 查推演记录表中同风格货品的 Top 人群重合度
  · 跃迁: 用户指定目标人群但该人群匹配度<60 → 强制输出"跨人群拯救方案"(改推匹配度最高人群)
  · 天花板: 对比 500+ 客单价竞品, 输出 100-300 元价格带差异化话术
第四步 连续失败检测: 该货品「连续未达标场次」≥ 3 → 强制输出【备选救场货品】
  (从货品表选毛利相近、风格反差、对 Top1 人群匹配度 ≥70 的替代款) + 切换战术
话术规则: 若价格分=15, 话术禁止出现"便宜/低价", 必须用"用 X 百元的价格,买 X 百元的做工"句式。
库存规则(v3 补): 现货深度=0 → 禁推; 低于安全库存线 → 标"限量场" + 输出"按近7场消耗速度还能撑 N 场"。
```

## 4.4 主播五力

```
主播综合得分 = 转化力×40% + 稳场力×25% + 留人力×15% + 引导力×10% + 涨粉力×10%
  · 转化力: 新访客 CVR、新访客 UV 价值
  · 稳场力: 后半段转化衰减率(衰减<15% 优秀, >35% 乏力)
  · 留人力: 10 秒留存率、人均停留时长
  · 引导力: 小黄车点击率
  · 涨粉力: 有效新增粉丝成本

三维联动决策:
  排品排班决策 = 主播五力短板 × 货品梯队位置 × SPM 人群匹配度
  · 主播"稳场力"弱 → 排品: 利润品放上半场, 下半场用福利款兜底
  · 主播"转化力"强但"留人力"弱 → 投流策略: 短平快投放, 不打持久战
  · 货盘四梯队漏斗: 引流品→爆品→利润品→清仓品, 流转流失率>40% 强制调序
（v3：低于90分的项自动标黄"建议加练"；App 服务端自动加权）
```

## 4.5 打法卡效果分（自迭代引擎）

```
效果分 = 采用该卡的场次中, 达标场次占比 × 100  (样本 < 5 场标"观察中", 不下结论)
效果分 < 40 → 自动降级回候选区;  < 25 → 淘汰出局
生命周期: 候选 → 启用 → 降级 → 淘汰
W2 每次推演必须记录"采用了哪张卡"; W3 周报对账实际结果, 自动回写效果分
删场次会反向重算（已实测: 删除后 uses 自动归零）; 全程 card_events 留痕可审计
```

## 4.6 单品五维分析

```
单品健康度 = 曝光点击率 × 点击成交CVR × (1-退款率) × 讲解产出 ÷ 类目均值
  · 讲解产出 = 单品GMV ÷ 口播时长(分钟) —— 找出"讲得久卖得少"的废款
  · 点击率达标但CVR低 = 价格/信任问题 → 改话术
  · 点击率就不达标 = 款不行 → 下架换品
```

## 4.7 单场损益与四层指标公式

```
单场净利 = 结算GMV(14天退款后) − 货品成本 − 千川消耗 − 平台扣点 − 物流包装 − 主播/运营分摊
（v3 前为简化版: 结算GMV − 千川 − 5%扣点; 缺口已列入 P0 Backlog）

【第一层 结果层】总UV | 前台GMV | 结算GMV(扣14天退款) | UV价值=结算GMV÷总UV | 客单价 | 退款率
  | GPM=结算GMV÷观看PV×1000
【第二层 链路漏斗】曝光进入率 | 10s留存 | 人均停留 | 商品点击率 | 点击-成交CVR | 整体CVR
【第三层 分层归因】自然UV价值/付费UV价值/自然CVR/付费CVR | 新粉UV价值/老粉UV价值/新粉成交占比
  | 前30min·中段·后段 UV价值衰减率
【第四层 盈利预测】千川消耗 | 毛利ROI | 单品投产 | 主播产出时薪 | 拉新成本 | 7日回访率

【周汇总自动公式】
  周UV价值 = SUM(每日结算GMV)/SUM(每日进场UV)
  转化衰减率 = (上半场UV价值−下半场UV价值)/上半场UV价值
  新粉成交占比 = SUM(新粉GMV)/SUM(总GMV)

【投流潜力标签·IF 自动判定】
  IF(付费UV价值 ≥ 自然×0.75 且 周UV价值 ≥ 类目中位, "✅可大额放量",
  IF(付费UV价值 ≥ 自然×0.5, "⚠️小预算测试",
  IF(总UV价值高 且 新粉占比<40%, "⚠️老粉直播间·禁止放量",
  "❌优化人货场·暂停投流")))

【其他关键判定】
  CVR = 订单 ÷ UV;  周均CVR = 近7天总订单 ÷ 总UV
  eCPM = 出价 × CVR × 1000（盯付费流量进入后 75 秒成交密度）
  放量硬门槛: 付费UV价值 ÷ 自然UV价值 ≥ 0.75（对应 L7）
  退款率红线: >25% 自动熔断该品并标记退款理由（仿宝石重点盯"掉色/褪色"）
```

## 4.8 爆品生命周期

```
测品期: 小流量试播, CTR ≥ 类目均值 → 晋级
上升期: SPM 推演锁定 Top1 人群, 投流配比 70% 打透
爆发期: 切片短视频同步引流, 库存预警
衰退期: 点击率连续 3 场下滑 → SPM 强制输出备选救场品切换
清仓期: 做引流款发挥余热, 给新爆品让位
```
