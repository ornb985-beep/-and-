# obsidian-skills：教 AI 使用 Obsidian 的技能包

- 维护者是 Obsidian 的 CEO Steph Ango（kepano）
- 技能：obsidian-markdown（双链、嵌入、提示框、属性）、obsidian-bases（.base 数据库视图、筛选、公式）、json-canvas（.canvas 白板）、obsidian-cli（命令行操作仓库）、defuddle（网页提取干净 Markdown）、knap（用 JSON/CSV 批量生成笔记）
- 安装（Claude Code，三选一）：
  1. `/plugin marketplace add kepano/obsidian-skills`，然后 `/plugin install obsidian@obsidian-skills`
  2. `npx skills add https://github.com/kepano/obsidian-skills`
  3. 手动：把仓库内容放进 Obsidian 仓库根目录的 `.claude` 文件夹
- Codex：把 `skills/` 目录复制到 `~/.codex/skills`
