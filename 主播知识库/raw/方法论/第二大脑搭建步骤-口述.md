# 如何从无到有搭一个能自我进化的第二大脑（原文）

下面从原子级环节拆开讲，如何从无到有搭一个能自我进化的第二大脑。

一、准备容器
1、下载安装 Obsidian，新建一个本地文件夹作为仓库。
2、在里面建两个子文件夹：raw 放原始资料，wiki 放 AI 整理后的知识库。
3、配同步：苹果用 iCloud，Windows 用 OneDrive，让多端文件一致。

二、接通 AI 手脚
1、安装 Claude Code，作为操作笔记的 Agent。
2、在终端跑命令，从 GitHub 拉取 obsidian-skills 插件包并安装、重载生效。

三、初始化知识库
1、在 Claude Code 输入框写入指令：学习 obsidian-skills 模板，基于 Karpathy 方法构建完整知识库，末尾加 ultra think 让模型深度思考。
2、运行后 AI 会自动扫描 raw 里的所有文件，生成概念页、实体页、摘要页，以及 Index 分类索引和 Log 操作日志。

四、往里灌资料
1、网页文章：装 Obsidian Web Clipper 浏览器插件，一键把正文提取成 Markdown 存入 raw。
2、视频：同一个插件会抓基础信息加带时间戳的字幕，一并存成 Markdown。
3、复杂网页：用 Claude Code 的浏览器插件，下指令让它直接操作页面、提取并总结。
