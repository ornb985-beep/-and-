# 05 · 在一个空文件夹里从零搭建（给别的领域 / 别的 AI 用）

先按 `README.md` 第一、二节准备好 Obsidian 和 AI，然后把下面整段发给 AI：

---

我要在当前文件夹里搭一个关于「主播训练与直播运营」的「第二大脑」，方法是 Andrej Karpathy 的 LLM Wiki。请：

1. 建目录：`raw/`（原始资料，只读）、`wiki/`（你维护的维基，下分 concepts / entities / sources / comparisons / synthesis / questions / data）、`outputs/`、`canvas/`、`bases/`、`templates/`、`prompts/`。
2. 写一份 `AGENTS.md` 规则：三层结构、页面类型与必填属性、录入 / 提问 / 体检三个操作的步骤、写作规则、禁止事项。再写 `CLAUDE.md`（内容只需一行 `@AGENTS.md` 加说明）。
3. 建 `wiki/index.md` 和 `wiki/log.md`（只追加，格式 `## [YYYY-MM-DD] 操作 | 标题`）。
4. 在 `templates/` 写概念页、实体页、摘要页、对比页、综合页、问题页模板。
5. 如果 `raw/` 里已经有资料，按「录入」流程全部处理一遍。
