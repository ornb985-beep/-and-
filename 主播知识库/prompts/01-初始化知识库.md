# 01 · 初始化知识库（第一次用，只做一次）

把下面整段复制到 Claude Code 输入框（其他 AI 同样适用）：

---

请先学习 `.claude/skills/` 里的 obsidian-skills 模板（obsidian-markdown、obsidian-bases、json-canvas、defuddle），再完整阅读根目录的 `AGENTS.md`。

然后基于 Andrej Karpathy 的 LLM Wiki 方法，把本仓库建成一个关于「主播训练与直播运营」的完整知识库：

1. 扫描 `raw/` 里的所有文件，一份一份读完。
2. 每份资料在 `wiki/sources/` 写一页摘要页。
3. 抽出所有概念写成概念页（`wiki/concepts/`），所有人物、平台、机构、工具写成实体页（`wiki/entities/`），容易混淆的写成对比页（`wiki/comparisons/`），跨资料的结论写成综合页（`wiki/synthesis/`），资料里没答案的写成问题页（`wiki/questions/`）。
4. 页面之间用 `[[双链]]` 充分互链；每页都有 YAML 属性（按 AGENTS.md 第 2 节）。
5. 生成 `wiki/index.md`（按类型分类、每页一句话摘要）和 `wiki/log.md`（只追加的操作日志，格式 `## [YYYY-MM-DD] 操作 | 标题`）。
6. 用 json-canvas 画一张总览白板放进 `canvas/`；如果有表格型数据，用 obsidian-bases 建一个数据库视图放进 `bases/`。
7. 最后做一次体检，把报告写进 `outputs/`。

规则：raw 只读；不编造；推算标「推算」；人名脱敏。
